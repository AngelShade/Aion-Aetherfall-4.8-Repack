AETHERFALL MULTI-CLIENT

Start Aetherfall Launcher.exe and press Play for your first game client.
To open another, reopen the launcher if it is minimized or closed and press
Play again. Reopening a minimized launcher brings its existing window back.
Use a different game account for each client; this does not change server
account-session rules.

Additional starts reuse the active renderer, graphics, cursor and flight
settings. Pending updates or renderer changes still require all Aion clients
closed. The startup helpers retain their existing file checks and reject
changes to files in use. This feature is built into the graphical launcher;
there is no extra injected DLL, game binary patch or background game process.
