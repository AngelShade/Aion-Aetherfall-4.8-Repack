# Speech frame artwork

Generated with the built-in image tool, transparent-background mode. Originals
are preserved in the generated-images folder; these project copies are the
production inputs. The integration only resizes and slices the images into
native DDS tiles.

`ornate.png` is **Wings**. Prompt:

> Use case: stylized-concept. Production game UI asset, one EMPTY Ornate Gold speech-bubble frame for a fantasy MMORPG like Aion. Create a clean horizontally oriented frame with a genuinely transparent exterior. A wide rectangular parchment-dark interior with subtly bowed sides, richly sculpted antique gold scrollwork at the four corners, winglike upper corner flourishes, substantial rounded bevelled gold rim, and a single elegant downward pointing speech tail centered on the bottom. Corners and tail must be clearly recognizable when the asset is rendered small. Interior is flat dark brown with no writing, no pattern, no gradient, and broad empty space for white game text. Straight middle stretches of all borders must be visually simple so the game can stretch them for longer messages. Front-facing orthographic UI artwork, precise crisp silhouette, sophisticated painted fantasy game style, no scene, no characters, no labels, no words, no watermark, no mockup. Frame fills most of image with a generous transparent margin on every side. Tail attached below the body; no other detached marks. This is a new UI frame artwork, not a color variant of a stock rounded speech balloon.

`amber.png` is **Crystal**. Prompt:

> Production fantasy MMORPG UI asset: one empty AMBER speech balloon frame. Genuinely transparent exterior. Wide compact horizontal hexagonal silhouette, distinctly clipped chamfered corners, sculpted bronze rim with bright amber crystal facets at corners, low stepped angular top and bottom, small asymmetrical lightning-shaped speech tail centered below. Flat dark warm charcoal interior, broad empty space for white text. Simple straight stretches of borders for nine-slice stretching. Crisp orthographic front view, no perspective, no text, no symbols, no characters, no scene, no mockup. This must be an angular geometric frame, very different from ornate scrollwork or a rounded balloon. Frame fills image with generous transparent margin. Bold recognizable silhouette at small sizes.

`thought.png` is **Cloud**. Prompt:

> Production fantasy MMORPG UI asset: one empty THOUGHT bubble frame, orthographic front-facing. Rounded fluffy cloud silhouette with large uneven scalloped lobes, softly bevelled pearly silver and pale blue rim, flat dark midnight blue interior with plenty of empty space for white game text. A descending chain of THREE small detached round thought dots centered beneath the cloud; no pointed speech tail. Wider than tall but much plumper than a compact speech balloon. Simple smooth middle stretches along rim so game can nine-slice stretch. Strong clear cloud silhouette at small sizes. Genuinely transparent exterior including around dots. No text, no symbols, no character, no scene, no mockup, no glow beyond rim. Clean detailed fantasy game UI art with substantial border, generous transparent margin. Must look like a thought cloud and have different geometry from hexagonal or ornate rectangular frames.

**Paws** uses Aion's original paw frame; **Classic** keeps the channel's original
frame. Neither stock texture was edited.
